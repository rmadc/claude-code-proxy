ClaudeGPT is an unofficial launcher for this fork, not an Anthropic or OpenAI product.
The icon pairs the Claude starburst and OpenAI/ChatGPT knot on separate badges.

Vendored SVG paths from Simple Icons (CC0-1.0 collection):
- Claude: https://cdn.jsdelivr.net/npm/simple-icons@16.0.0/icons/claude.svg
- OpenAI: https://cdn.jsdelivr.net/npm/simple-icons@13.0.0/icons/openai.svg
- Collection license: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Brand names and marks remain the property of their respective owners. Collection
licensing does not grant trademark rights or imply endorsement.

`ClaudeGPT.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel images. Releases use
this checked-in asset without fetching artwork or running a browser during builds.
To regenerate locally on Windows, run `scripts/build-claudegpt-icon.ps1`.
